### 2026-09-05: Competitor brand cross-check is an advisory ingestion enrichment
**By:** Backend
**What:** Tool generation now enriches the stored brand snapshot with a `competitorContext` advisory block. It uses a cheap Anthropic structured prompt to identify 2-3 direct competitors, then reuses the same Context.dev ingestion path already used for the target brand (`pullBrandProfile()` and its underlying Context.dev calls) to derive each competitor's palette/font/logo signals before aggregating norms and surfacing a non-blocking sanity signal in the dashboard.
**Why:** This keeps the competitor cross-check aligned with the fully cut-over Context.dev pipeline instead of reintroducing deprecated Firecrawl dependencies. Per-competitor failures still degrade softly into advisory notes so tool generation never blocks on competitor lookups.
