### 2026-09-05: Build page redesigned as split-pane chat + live preview workspace
**By:** Frontend
**What:** Replaced the old card/form build page with a Base44-inspired split-pane workspace: a chat-style left rail for tool setup, prompting, revisions, and pipeline activity; a top project switcher / preview-dashboard bar; and a right-side preview canvas with a matching dashboard tab for embed snippets, brand snapshot details, recent tools, and version rollback. Required tool-name validation still happens before every generate/update request, and updates now flow through the same chat composer instead of a separate button cluster.
**Why:** The old layout exposed every feature at once but felt like an admin form instead of an AI builder. The new information architecture keeps the differentiating live preview front-and-center, moves operational details into the Dashboard tab, preserves recent-tool reopening via the top-left switcher/list, and makes the edit loop feel conversational. Progress steps are currently honest client-side estimates based on the real orchestrator phases and observed generation timings; true backend-streamed stage events are deferred as a safer follow-up because Backend is actively changing the generation pipeline files this UI depends on.
