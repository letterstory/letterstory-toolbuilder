### 2026-09-05: Build page redesigned as split-pane chat + live preview workspace

**By:** Frontend
**What:** Replaced the old card/form build page with a Base44-inspired split-pane workspace: a chat-style left rail for tool setup, prompting, revisions, and pipeline activity; a top project switcher / preview-dashboard bar; and a right-side preview canvas with a matching dashboard tab for embed snippets, brand snapshot details, recent tools, and version rollback. Required tool-name validation still happens before every generate/update request, and updates now flow through the same chat composer instead of a separate button cluster. A persistent brand-summary card now surfaces the detected logo/colors/fonts in the left rail after ingestion, and the top-right Publish CTA now routes users straight to the Dashboard's hosted iframe/embed section instead of implying a separate publishing backend.
**Why:** The old layout exposed every feature at once but felt like an admin form instead of an AI builder. The new information architecture keeps the differentiating live preview front-and-center, makes brand ingestion visibly legible as part of the product instead of background "thinking," surfaces hosted iframe delivery as the primary publish action, preserves recent-tool reopening via the top-left switcher/list, and makes the edit loop feel conversational. After reviewing Base44's live DOM/CSS, I also tightened the interaction pattern to match higher-value structural details more closely: 360px chat rail, denser 52px-style chrome, dark submit/publish buttons, bordered badge pills, display-font-only loading headline, animated dots/progress line, and no full-canvas takeover during in-place updates. The visual system still uses LetterStory's existing `globals.css` brand tokens for accent states rather than carrying over Base44's palette. Progress steps remain honest client-side estimates based on the real orchestrator phases and observed generation timings; true backend-streamed stage events are deferred as a safer follow-up because Backend is actively changing the generation pipeline files this UI depends on.
