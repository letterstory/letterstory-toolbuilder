### 2026-09-06: Recent tools dropdown now supports duplicate actions
**By:** Frontend
**What:** I added a non-destructive Duplicate action to each row in the Recent tools dropdown and threaded a new `onDuplicateRecent(tool)` callback from `ToolBuilderWorkspace` into `BuilderTopbar`. The duplicate flow resets the workspace to a true new-tool state, then pre-fills only the source tool's brand site and saved prompt while leaving the tool name blank. It also focuses the composer, switches back to Preview, and closes the dropdown so the user can immediately refine and generate the duplicate.
**Why:** Users already have the inputs needed to generate a brand-new tool from arbitrary site+prompt data. Reusing those inputs from an existing saved tool reduces retyping friction, while deliberately clearing `projectName` and `activeTool` avoids confusing the duplicate with the original and guarantees the next submission creates a new record instead of overwriting the source tool.
