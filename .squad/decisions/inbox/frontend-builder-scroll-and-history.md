### 2026-09-06: Fixed full-bleed layout height chain so desktop chat scrolls independently again
**By:** Frontend
**What:** I corrected the shared dashboard shell so desktop now uses `lg:h-dvh lg:overflow-hidden` while mobile drops back to ordinary document flow instead of staying in a flex-bounded viewport shell. `<main>` is now only a flex/scroll container at `lg`, and the `/build` page keeps its overflow clipping gated to `lg` only. That restores the bounded desktop height chain needed for split-pane scrolling — layout root → main → build page wrapper → workspace → desktop grid → chat/right panes — while letting the stacked mobile layout and `/brand` route keep normal page scrolling.
**Why:** With only a minimum height, the desktop dashboard container could grow taller than the viewport, so the browser page scrollbar took over and the left chat pane never got a real clipped ancestor to scroll inside. Using a desktop-only fixed viewport height fixes that regression, and making the entire bounded-height/flex chain responsive prevents the mobile build page from getting trapped inside an unintended internal scroll container.
