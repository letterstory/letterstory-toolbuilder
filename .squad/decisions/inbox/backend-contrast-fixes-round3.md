### 2026-09-05: Verified tool-title copy now shares the deterministic neutral surface used by the brand lockup
**By:** Backend
**What:** `buildEnforcementCss()` now applies the same dedicated white, padded, rounded, bordered surface to `.ls-brand-verified-copy` that already protected `.ls-brand-lockup--exact_asset` and `.ls-brand-lockup--text_only`, while keeping the title `h1` on the brand text color inside that known-safe surface.
**Why:** The remaining Gymshark failure was the same root cause as the prior lockup bug in a third location: deterministic brand text (`colors.text`, black) was being injected directly into an LLM-authored `<header>` whose background could also be black, making the title invisible. Reusing the neutral enforcement surface fixes the collision without trying to parse arbitrary model CSS, and a follow-up sweep of `brand-enforcement.ts` confirmed the wordmark is still only rendered inside the protected lockup surface so there was no fourth free-floating brand-colored text element to patch.
